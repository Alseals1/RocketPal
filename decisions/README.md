# Decisions

Non-trivial decisions the agents made on their own, one file each: `decisions/YYYY-MM-DD-<topic>.md`.

Each file says what was decided, why, and what the alternatives were, so the user can review later without being asked. Critical decisions (money, installs or device settings, accounts and secrets, deletions, data collection, licensing) are never logged here instead of asking: they go to the user first.
